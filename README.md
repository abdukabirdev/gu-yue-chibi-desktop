# Chibi Walker — Desktop

Чиби-маскот из расширения [Chibi Walker](https://github.com/abdukabirdev/gu-yue-chibi-walker), который живёт прямо на рабочем столе Windows: гуляет по панели задач, лазает по краям экрана, висит на верхнем краю, летает (образ «Плащ»), его можно схватить мышкой и бросить.

Сделано на [Tauri 2](https://tauri.app): прозрачное окно поверх всех, клики проходят сквозь него везде, кроме самого чиби. Клик по чиби не забирает фокус у программы, в которой ты работаешь.

## Что умеет

- Ходьба, бег, моргание, эмоции, медитация, сон — те же 160+ кадров, что в расширении.
- Бросок мышкой с физикой: отскоки, кувырок, шлепок лицом и потирание шишки.
- Лазание по левому/правому краю экрана и вис на верхнем.
- Полёт (цингун) — образ «Плащ»; двойной клик по нему — полетать.
- Две маски: милый и суровый — меняются сами (в рабочее время чаще суровый), или выбери в трее.
- Засыпает, когда ты 2 минуты не трогаешь компьютер, и встречает, когда возвращаешься.
- Иногда бежит к курсору.

Меню — в иконке в трее: позвать, полетать, уложить спать, образ, настроение, размер, спрятать, выход.

## Запуск из исходников

Нужны: [Node.js](https://nodejs.org), [Rust](https://rustup.rs), Visual Studio Build Tools (C++), WebView2 (есть в Windows 10/11).

```bash
npm install
npm run dev      # запуск в режиме разработки
npm run build    # установщик: src-tauri/target/release/bundle/nsis/
```

## Структура

- `src/` — фронтенд: `main.js` (движок маскота), `style.css`, `poses/` (кадры и `skin.json` образов).
- `src-tauri/src/main.rs` — окно на рабочую область экрана, сквозные клики, трей, время бездействия пользователя.
