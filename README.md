# Chibi Walker — Desktop

Чиби-маскот из расширения [Chibi Walker](https://github.com/abdukabirdev/gu-yue-chibi-walker), который живёт прямо на рабочем столе Windows: гуляет по панели задач, лазает по краям экрана, висит на верхнем краю, летает (образ «Плащ»), его можно схватить мышкой и бросить.

Сделано на [Tauri 2](https://tauri.app): прозрачное окно поверх всех, клики проходят сквозь него везде, кроме самого чиби. Клик по чиби не забирает фокус у программы, в которой ты работаешь.

## Что умеет

- Ходьба, бег, моргание, эмоции, медитация, сон — те же 160+ кадров, что в расширении.
- Бросок мышкой с физикой: отскоки, кувырок, шлепок лицом и потирание шишки.
- Лазание по левому/правому краю экрана и вис на верхнем.
- Полёт (цингун) — образ «Плащ»; двойной клик по нему — полетать.
- Две маски: милый и суровый — меняются сами (в рабочее время чаще суровый), или выбери в трее.
- Засыпает, когда ты 2 минуты не трогаешь компьютер, и встречает, когда возвращаешься.
- Когда ты долго ничего не нажимал, иногда бежит к курсору.

### Не мешает работать

- Пока ты работаешь, держится пустых мест (где внизу нет окон) и краёв экрана. В центр выходит, только когда ты минуту ничего не трогаешь.
- Отходит от места, где ты печатаешь или кликаешь: от каретки ввода и последнего клика. Поле ввода внизу окна он не закрывает.
- Курсор подбирается к нему, и первые ~2 секунды он уступает дорогу: становится полупрозрачным, клики проходят сквозь него к кнопке под ним, и он отбегает. Гонишься дольше — сдаётся, и его можно схватить. С зажатым **Ctrl** ловится сразу. Если ты вернулся после перерыва и сразу идёшь к нему, убегать не будет.
- Когда сверху вкладки и заголовки окон, по краю лезет невысоко и не висит наверху.
- Видео, игра или презентация на весь экран — прячется. «Не мешать 30 минут» — прячется на полчаса.

### Смотрит, что ты делаешь

- Узнаёт активную программу: редактор кода, браузер (YouTube, GitHub, Stack Overflow, поиск, нейросети), терминал, мессенджер, Office, Проводник — и изредка комментирует. Переписку, почту и банки не читает.
- Читает код: в VS Code, Cursor, Windsurf, JetBrains и Notepad++ находит открытый файл на диске по заголовку окна. Называет язык и функции, ловит TODO, `console.log`, ключи в коде, SQL-инъекции, пустые `catch` и `==`. Без замечаний чаще молчит.
- Смотрит, что ты скопировал: JSON (валидный или нет), Unix-время, цвет, base64, JWT, cron, регулярка, HTTP-код, текст ошибки, код. Пароли из менеджеров паролей и похожие на пароль строки пропускает.
- Всё читается только на этом компьютере, без нейросети и никуда не отправляется.

Меню — **правый клик по чиби**: что я делаю, что в буфере, полетать, медитировать, спать, образ, нрав, размер, не мешать 30 минут, выход. Те же пункты и «Позвать» — в иконке в трее.

## Запуск из исходников

Нужны: [Node.js](https://nodejs.org), [Rust](https://rustup.rs), Visual Studio Build Tools (C++), WebView2 (есть в Windows 10/11).

```bash
npm install
npm run dev      # запуск в режиме разработки
npm run build    # установщик: src-tauri/target/release/bundle/nsis/
```

## Структура

- `src/` — фронтенд: `main.js` (движок маскота), `brain.js` (понимание кода и текста без нейросети), `style.css`, `poses/` (кадры и `skin.json` образов).
- `src-tauri/src/main.rs` — окно на рабочую область экрана, сквозные клики, трей; окружение для маскота: окна приложений, активное окно, каретка, клики и печать, буфер обмена, чтение открытого в редакторе файла.
